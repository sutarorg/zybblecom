# Zybble scraper worker — Python runtime dependencies.

# source and worker/gmaps_engine.py runs as a child process. It drives Chromium
# through Playwright, so this image needs no Selenium, no chromedriver and no
# BeautifulSoup — all three went away with the retired vendored scraper.
#
# requests   → Nominatim geocoding (coverage.py), public social-profile
#              enrichment (site_enrichment.py), and the /api/worker/* control
#              plane (worker.py)
# dnspython  → DNS MX verification of every address the engine published
#              (engine_contacts.py)
