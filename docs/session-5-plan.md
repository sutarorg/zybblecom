# Integration audit and execution order

The branch starts at the Sessions 1–4 merge. Marketing serves shared pack objects; the account forms use `FrontendServices`, creator pages use `WorkspaceAdapter`, and `/admin` uses guarded `AdminReads` plus separate commands. None originally calls a provider. Keep these seams and the existing UI. No hosted account configuration or provider credentials are available in this workspace. Enable the existing Supabase and Vercel connections for hosted operations; enter provider credentials in secret settings only.

1. Database constraints, explicit RLS/grants, wallet transaction tests; then cookie-based Auth and guards.
2. Central minor-unit pricing, exact Dodo products, signed webhook and atomic fulfillment; test duplicate deliveries before enabling moving money.
3. Private uploads with verified immutable object metadata, server-derived duration or approved conservative preauthorization; reject unverified video.
4. Durable job dispatch, reconciliation and separate asset copy. ClipSDK requires identical body under an idempotency key for 24h; persist the signed submission body privately, not just the key. Reconcile unknown responses before any new submission. Never infer missing webhook as failure.
5. Connect private reads and mutations in both interfaces, then run provider sandbox, security, browser and launch gates. Production remains blocked without those checks.
